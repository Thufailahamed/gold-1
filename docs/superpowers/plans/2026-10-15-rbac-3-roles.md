# RBAC 3 Roles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace 8 roles with exactly 3 (owner, admin, staff); only owner sees final accounts/profits; staff can sell + close day.

**Architecture:** Permission-based RBAC stays. Add `dayclose:view` + `dayclose:manage` for operational close; keep `accounts:view/manage` as owner-only financials. Strip cost/COGS fields for callers without `accounts:view`.

**Tech Stack:** Hono + D1/Drizzle, Next.js web, Expo mobile, @goldos/shared Zod + permissions.

**Spec:** User request 2026-10-15: roles owner/admin/staff only; owner-only final accounts + profits; staff can make sales + close day.

## Global Constraints

- Authorization is permission-based — code never checks role names (docs/permissions.md).
- Every write batches business change + audit_logs in ONE atomic batch.
- Never edit an applied migration; new migration 0047.
- Strict TypeScript, no `any`.
- `entry_date` shop-local TEXT YYYY-MM-DD; day lock stays in buildEntryStmts + triggers.

## Review Focus

- Staff calling GET /accounts/* or /monthly/pnl expects 403, never profit numbers.
- Staff GET sale detail expects no cost_cents and no COGS (5000/1100) journal lines.
- Staff POST day-close expects 201; POST reopen expects 403.
- Old DB with manager/cashier users expects remap to admin/staff, no orphan roles.
- Sidebar/mobile expects no Accounts/Reports links for staff, Day Closing visible.

Migration SQL (idempotent):
```sql
INSERT INTO permissions ... dayclose:view, dayclose:manage;
INSERT INTO roles ... admin, staff;
-- grant owner all, admin matrix, staff matrix (explicit VALUES);
UPDATE user_roles SET role_id='admin' WHERE role_id IN ('manager','accountant');
UPDATE user_roles SET role_id='staff' WHERE role_id IN ('cashier','salesperson','inventory_officer','gold_officer','manufacturing_staff');
DELETE FROM role_permissions WHERE role_id IN (old 5);
DELETE FROM roles WHERE id IN (old 5);
```
